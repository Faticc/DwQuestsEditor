# Тестовые вкладки квестов

Папку можно открыть целиком: **Файл → Открыть папку…** и указать `testquests`.
Слева появится список всех четырёх вкладок, в просмотре — та же колонка, что в игре.

| Вкладка | Квестов | Связей | Задач | Зачем |
|---|---:|---:|---:|---|
| `Начало.json` | 24 | 22 | ~47 | обычная работа: правка, перетаскивание, связи |
| `Магия.json` | 120 | 118 | ~220 | средняя вкладка, видно подписи и дуги |
| `Техника.json` | 400 | 422 | ~790 | столько бывает в настоящей сборке |
| `Огромная.json` | 1200 | 1274 | ~2390 | запас прочности: замеры скорости и прокрутка |

Внутри специально намешано всё, что редактор должен уметь показать:

* все шесть редкостей, все восемь типов узлов, размеры `MEDIUM`/`LARGE`/`HUGE`;
* зависимости и строкой, и объектом — с `FAKE` и `HIDDEN`, с линиями `INVERTED`;
* задачи `ITEM_DETECT` / `ITEM_PASS` / `ITEM_CRAFT` / `ITEM_SMELT` / `ENTITY_KILL` /
  `TASK_CONFIRM`, у части — зависимости между задачами и `tasksType: SEQUENTIAL`;
* награды: предметы с количеством, `command:…` и гифты с NBT;
* описания с `<BR>`, `<RI>` и §-кодами, у части квестов — `broadcast`
  с плейсхолдерами `%nick%` / `%quest%` / `%tab%`;
* длинные дуги через полкарты — связи между разными ветвями.

Проверить, что всё читается:

```bash
java -Dfile.encoding=UTF-8 -cp "out;lib/*" ru.dw.qeditor.cli.QuestCli validate testquests/Огромная.json
```

Замер скорости на самой большой:

```bash
java -Dfile.encoding=UTF-8 -cp "out;lib/*" ru.dw.qeditor.util.Bench testquests/Огромная.json 20 1920 1080
```

Пересобрать или сделать другие размеры — `make.py` (нужен Python 3):

```bash
python testquests/make.py testquests
```

Размеры и число ветвей задаются в конце файла, в `main()`.
