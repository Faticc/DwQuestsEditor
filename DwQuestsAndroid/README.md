# DwQuests Editor для Android

Тот же редактор вкладок, что на компьютере, — карта, просмотр как в игре, панель
квеста, задачи, награды, гифты и пакеты, история версий, проверка и сверка id, —
под Android 8–16 (собирается под API 36). Иконки предметов пака и текстуры мода
встроены в APK, ничего докачивать не нужно. **Моста с игрой нет**: вкладку в игру
переносят через буфер («Копировать для /dwq tab paste») или файлом.

## Сборка

Нужны JDK 17+ и Android SDK (platform 36, build-tools 36). Путь к SDK —
`local.properties` (`sdk.dir=…`) или `ANDROID_HOME`.

```bash
cd DwQuestsAndroid
LANG=C.UTF-8 ./gradlew assembleRelease
# → build/outputs/apk/release/DwQuestsAndroid-release.apk
```

`LANG=C.UTF-8` обязателен на Linux без локали: в `runtime/` есть файлы с
кириллицей в имени, и JVM Gradle иначе их не находит.

APK подписан ключом из `keystore/` — он лежит в репозитории нарочно, чтобы новая
сборка с любой машины ставилась поверх прежней. Секретом не является.

## Как устроено

Своей копии редактора тут почти нет. `build.gradle` берёт общие исходники из
`DwQuestsBridge/src/main/java/ru/dw/qeditor` и переписывает импорты:

| В общем коде | На Android |
|---|---|
| `org.lwjgl.opengl.GL33C` | `android/gles/GL33C` — те же вызовы поверх GLES 3.0, шейдеры получают `#version 300 es` |
| `org.lwjgl.system.MemoryUtil` | `android/gles/MemoryUtil` — прямые буферы |
| `java.awt.*`, `javax.imageio.ImageIO` | `android/awt/*` — `BufferedImage` на массиве ARGB, чтение и запись PNG через `Bitmap` |

Файл в `src/main/overlay` по тому же пути заменяет общий целиком:

* `app/App` — окно под палец: на узком экране разделы «Вкладки / Карта / Квест /
  Просмотр / JSON», на планшете — три колонки; залипающие «Связь» (Shift) и
  «Набор» (Ctrl); импорт, «Поделиться», примеры; черновик несохранённого при
  уходе в фон;
* `app/FileDialogs` — выбор файла и папки своим окном (системный выбор Android
  отдаёт адрес, а не путь, а редактор весь на файлах);
* `app/SettingsDialog`, `assets/Config` — размер интерфейса в % от системного,
  настройки в каталоге приложения;
* `gl/UiFont` — шрифт интерфейса через `Paint`;
* `render/GifWriter` — та же палитра, своя запись GIF (LZW).

`src/main/java/ru/dw/qeditor/android`:

* `TouchInput` — жесты → события мыши и клавиатуры для интерфейса (тап, двойной,
  долгое нажатие = ПКМ, тяга, два пальца = панорама и зум колесом); события
  отдаются кадрами, с границами между нажатием и отпусканием;
* `EditorView` — `GLSurfaceView`, кадры по требованию, клавиатура телефона
  (составной ввод переводится в Backspace + символы), внешняя клавиатура и мышь;
* `MainActivity` — доступ к памяти, импорт/экспорт через системный выбор,
  «Поделиться» (`ShareProvider`), «Открыть с помощью», «Назад» = Esc,
  строка «Всё / Копировать / Вставить / ↶ …» над клавиатурой;
* `ApkAssets` — ресурсы из APK по списку `dwq-index.txt` (его пишет сборка).

## Файлы на телефоне

С доступом ко всем файлам (спрашивается при первом запуске) вкладки по умолчанию
лежат в `Документы/DwQuests`, и можно открыть любую папку. Без него — в каталоге
приложения; туда и оттуда — «Файл → Импорт вкладок из телефона» и «Поделиться» /
«Сохранить копию в…». Версии вкладок, как и на компьютере, — в `.backups` рядом.

## Проверка без телефона

Эмулятору нужна аппаратная виртуализация, поэтому окно Android-сборки можно
снять на компьютере: `devtools/probe.sh` компилирует общий код с окном,
файлами и жестами из этой сборки (они без `android.*`) и рисует кадр через
LWJGL в скрытом окне (Xvfb + Mesa), а касания задаются сценарием:

```bash
devtools/probe.sh /tmp/shots 1080 2400 2.625 сценарий.txt ../DwQuestsEditor/testquests/Начало.json
```

```text
tap 126 406          # координаты в dp
double 126 406
long 300 640
drag 126 406 230 470
pinch 200 500 100 260
pan2 200 500 0 -150
type Привет
key 259              # код GLFW (Backspace)
shot имя             # → /tmp/shots/имя.png
```

Иконка приложения рисуется тем же узлом квеста:
`MAIN=ru.dw.qeditor.devtools.IconProbe devtools/probe.sh "$PWD/src/main/res"`.
