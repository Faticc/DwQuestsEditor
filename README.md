# DwQuests Editor

Редактор вкладок квестов для мода **DwQuests** (Minecraft 1.7.10). Java + LWJGL:
окно, интерфейс и карта рисует OpenGL. Нужен JDK 17+ и видеокарта с OpenGL 3.3;
зависимости подтягивает обёртка Maven из репозитория.

Отличие от [веб-редактора kriss-ss](https://github.com/kriss-ss/DwQuestsEditor): вкладка
«Просмотр как в игре» — это не приблизительная имитация, а порт игрового окна
`GuiStarAtlas`. Тот же шрифт Minecraft, те же цвета редкостей, звёзды-ноды
с анимацией, волнистые линии зависимостей, фоны вкладок и панель квеста — вплоть до
формул из шейдеров `circle.frag` / `gradient.frag`, которые теперь и считает
видеокарта, как в самом моде.

## Возможности

**Полный экран** — `F11` или кнопка «Во весь экран»: остаётся только карта,
боковые панели, меню и строка состояния прячутся. Полоска разделов сверху
остаётся, чтобы переключаться между редактором и просмотром не выходя из режима.
Выход — `F11` или `Esc`.

**Папка с квестами** — открывается целиком: слева список всех вкладок с иконками
и числом квестов, переключение одним щелчком, создание вкладки прямо в папке.

**История версий** — копия вкладки сохраняется при каждом сохранении, раз в
несколько минут при несохранённых правках и перед рискованными действиями
(правка помощником, раскладка сеткой, переключение вкладки, откат). Версии лежат
в `.backups/<вкладка>/` рядом с файлом; в «Инструменты → История версий» видно,
чем версия отличается от текущего состояния, и можно вернуться к ней.

**Поле редактора** — сетка с настраиваемым шагом и сдвигом, привязка, перетаскивание
с мультивыделением и рамкой, `Shift`+ЛКМ — протянуть зависимость, `Shift`+ПКМ по линии —
удалить, контекстное меню, зум и панорама, undo/redo, автосохранение черновика.
Название квеста показывается под курсором и у выделенных — постоянным размером
на экране, поэтому не мылится от зума; кнопка «все имена» включает подписи у всех.

**Просмотр как в игре** — карта квестов с зумом 1..2 и панорамой, панель квеста
с описанием (`<BR>`, `<RI>`, `<IMG>`, `§`-коды), задачами и наградами. Слева, как в
игре, список всех вкладок папки с общим прогрессом — между ними можно переключаться
прямо в просмотре. Прогресс игрока редактору неизвестен, поэтому есть режимы
«все выполнены / все активны / смешанный».

**Свойства квеста** — имя, иконка, координаты, редкость, размер узла, тип узла, режим
задач; описание с кнопками форматирования, палитрой 16 цветов и живым предпросмотром
игровым шрифтом.

**Задачи** — все 27 типов из `IQuestTask.Type`; те 20, что сервер не отслеживает,
помечаются предупреждением. Перетаскивание строк, копирование, перенумерация.

**Награды** — предметы, команды (`command:…`), гифты и скриптовые предметы
`customnpcs:scripted_item`. Редактор гифтов повторяет игровой `GuiContainerGift`:
карусель текстур и слоёв, имя и лор игровым шрифтом, тип выдачи, сетка предметов 3×9.
Для предметов с произвольным NBT есть отдельный редактор с проверкой синтаксиса.

**Оповещение** (`broadcast`) — плейсхолдеры `%nick%`, `%player%`, `%quest%`, `%tab%`
и предпросмотр того, что увидят в чате.

**Выбор предмета** — поиск по русскому имени, id или моду среди всех предметов сборки,
ручной ввод строки с метой, количеством и NBT.

**Проверка вкладки** — битые ссылки в зависимостях, циклы, дубли координат,
отсутствующие иконки, `requiredCount = 0`, задачи без серверной поддержки.

**Помощник Claude** — правка вкладки текстовым запросом через локальный
[Claude Code](https://claude.com/claude-code) CLI; отдельный ключ API не нужен.
Ответ не применяется сразу: сначала показывается сводка изменений и проверка.

**Консольный режим** — 20 команд для правок из терминала или скриптом.
Видеокарта ему не нужна.

## Как отдать редактор человеку

```bash
package.bat
```

Собирает два варианта в `dist/`; **все ассеты внутри** — ни папок рядом, ни
настройки путей получателю не нужно:

| Что | Размер | Что нужно получателю |
|---|---|---|
| `dist/DwQuestsEditor-win64.zip` | 134 МБ | ничего: распаковать и запустить `DwQuestsEditor.exe` |
| `dist/jar/DwQuestsEditor.jar` | 111 МБ | Java 17+, запуск двойным щелчком |

В zip лежит папка с exe, иконкой и урезанной Java (`java.base`, `java.desktop`,
`jdk.unsupported` — последний обязателен, иначе LWJGL не стартует).
Отдавать надо всю папку целиком.

Только один из вариантов: `package.bat jar` или `package.bat exe`.

## Сборка из исходников

```bash
git clone https://github.com/Faticc/DwQuestsEditor.git
cd DwQuestsEditor/DwQuestsEditor
build.bat        # скачает LWJGL в lib и соберёт классы в out
run.bat          # запуск; можно передать файл вкладки
```

Всё нужное для работы лежит в репозитории в `runtime/`: `icons/` — иконки
предметов и их русские названия, `game/assets/…` — текстуры мода и шрифт
Minecraft, вытащенные из jar-ов. Установленный клиент и сами моды не нужны.

Или вручную:

```bash
mvnw -B compile                       # или: mvnw -B dependency:copy-dependencies
find src -name "*.java" > sources.txt
javac -encoding UTF-8 -cp "lib/*" -d out @sources.txt
java -Dfile.encoding=UTF-8 -cp "out;lib/*" ru.dw.qeditor.Main
```

Кодировку указывать обязательно — иначе ломается кириллица.

## Настройка путей

Настраивать ничего не нужно: ресурсы либо лежат в `runtime/` рядом с
программой, либо вшиты в её jar. Поля в «Инструменты → Настройки» нужны только
чтобы подложить свои:

| Что | Зачем |
|---|---|
| Папка иконок (`img/`, `json/items.json`) | свежий экспорт иконок из клиента |
| Папка ресурсов мода (внутри `assets/…`) | обновлённые текстуры и фоны вкладок |

Пустое поле = берётся встроенное. Там же настраивается история версий: сколько
копий хранить на вкладку, как часто делать автоматическую копию и делать ли её
при каждом сохранении.

Проверить, откуда что читается: «Инструменты → Диагностика».

## Консольный режим

```bash
dwq.bat help
```

```bash
dwq.bat tabs C:/quests                  # что лежит в папке
dwq.bat new Botania.json --tab Botania
dwq.bat add Botania.json Начало --name "Первые шаги" --x 0 --y 0 --icon minecraft:book
dwq.bat task-add Botania.json Начало --type ITEM_DETECT --item minecraft:log --count 16
dwq.bat add Botania.json Дерево --x 2 --y 0 --icon minecraft:log --parent Начало \
        --reward "minecraft:diamond=3"
dwq.bat validate Botania.json

dwq.bat versions Botania.json           # сохранённые версии
dwq.bat backup Botania.json             # копия прямо сейчас
dwq.bat restore Botania.json --version 2
```

Открытый в окне файл перечитывается автоматически, если изменить его снаружи, — окно
и консоль можно использовать одновременно.

## Формат вкладки

```jsonc
{
  "tabID": "Botania",
  "iconItem": "minecraft:book",
  "sortIndex": 0,
  "quests": {
    "Начало": {
      "displayX": 0, "displayY": 0,          // в игре умножаются на 24
      "displayName": "Первые шаги",
      "description": "<BR>Собери первые ресурсы.",
      "iconItem": "minecraft:book",
      "rarity": "COMMON",
      "parents": [],
      "tasks": { "0": { "type": "ITEM_DETECT", "requiredCount": 16,
                        "forgeName": "minecraft:log" } },
      "rewards": ["minecraft:diamond=3"]
    }
  }
}
```

Готовую вкладку можно скопировать в буфер («Файл → Копировать для `/dwq tab paste`»)
и вставить в игре командой `/dwq tab paste <имя>`.

## Замечания

* Редактируется одна вкладка за раз, но переключение между вкладками папки — в один щелчок.
* Скрытые связи (`HIDDEN`) мод не рисует вовсе; в редакторе они видны тонкой серой
  линией, как в веб-редакторе, и отключаются кнопкой «скрытые».
* Скорость: вкладка в 1200 квестов и 1274 связи на 1920×1080 — около 59 кадров
  в секунду в поле редактора и 139 в просмотре; на вкладке в 400 квестов —
  122 и 178. Пока ничего не происходит, кадры вообще не рисуются: окно ждёт
  события.
* Тестовые вкладки на 24 / 120 / 400 / 1200 квестов лежат в
  [`DwQuestsEditor/testquests/`](DwQuestsEditor/testquests/) — папку можно открыть
  целиком.
* Подробности реализации и разбор исходников мода — в [PROGRESS.md](PROGRESS.md),
  памятка для работы с проектом — в [CLAUDE.md](CLAUDE.md).
